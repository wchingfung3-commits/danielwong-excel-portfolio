Project 03 · Data quality

Customer & Order Data Cleanup System

A controlled Excel workflow for detecting duplicate records, standardizing business labels and producing validation-ready output.

Source rows1,250
Duplicates86
Incomplete42
Clean output1,122

Challenge

The dataset mixed duplicate order IDs, inconsistent customer names, abbreviated regions, irregular status labels and incomplete customer fields. These issues would create unreliable reporting and import errors.

Approach

  • Applied duplicate checks to order identifiers.
  • Standardized customer, region and order-status labels.
  • Flagged incomplete records for review instead of silently filling assumptions.
  • Used controlled values and clear quality indicators for handover.

Outcome

The cleanup reduced 1,250 source rows to 1,122 validated output rows. The resulting structure is designed for downstream reporting, system import or operational review.
